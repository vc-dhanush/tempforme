# Dhanush V C — Portfolio

Premium multi-page personal portfolio for **Dhanush V C** (AI/ML Engineer · Computer Vision · Software Developer).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion (subtle, respects `prefers-reduced-motion`)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Content

All site copy lives in `src/data/content.ts`. Update projects, research, experience, and links there.

Assets:

- Profile: `public/images/profile.jpg`
- Resume: `public/documents/Dhanush_VC_Resume.pdf`

## Pages

- `/` Home
- `/about` About
- `/experience` Experience
- `/projects` + `/projects/[slug]`
- `/research` + `/research/[slug]`
- `/skills` Skills
- `/achievements` Achievements
- `/certifications` Certifications
- `/gallery` Gallery
- `/contact` Contact
